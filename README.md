# Farming-2
Chào mừng bạn đến với Farming-2, nơi bạn được hóa thân thành một người nông dân thực thụ! Hãy khám phá vùng đất xanh mướt, gieo trồng các loại cây như khoai tây, cà chua, thu hoạch nông sản, mở rộng trang trại và giao thương cùng NPC trong làng.
Trò chơi nông trại lấy cảm hứng từ Stardew Valley được phát triển bằng Unity.
# Công nghệ sử dụng
- C# với Unity - phiên bản 6000.1.2f1
- Google Firebase Database
# Gameplay
- Đào đất
- Trồng và chăm sóc cây trồng theo thời gian thực
- Thu hoạch
- Mua bán hạt giống, nông sản trong hệ thống cửa hàng
- Kiếm tiền, nâng cấp trang trại và trở thành tỷ phú nông dân!
